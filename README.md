# REV MOTO — Modern Motorcycle & Electric Bike Gear Store

A responsive, high-performance e-commerce storefront for **REV MOTO**, featuring technical aerodynamic motorcycle armor, carbon-fiber riding gloves, modular luggage packs, and electric velocity apparel.

## ✨ Key Features

- **Luxury Cyber-EV Aesthetics**: Translucent pill navigation, subtle glows, and clean responsive typography.
- **Full Catalog & Filtering**: Categorized browsing for riding jackets, carbon gloves, luggage packs, and anti-fog face masks.
- **Interactive Product Details**: Size selectors, dynamic variation pricing, image gallery with hover-to-zoom, and size guide modal.
- **Cart & Fast Checkout**:
  - Floating slide-out cart drawer with animated add-to-bag bezier effects.
  - Cart bag page with real-time subtotal and nationwide delivery calculator.
  - Multi-step checkout with Cash on Delivery (COD) and WhatsApp direct order integration.
- **Ultra-Smooth Momentum Gliding**: Integrated Lenis scroll physics with modal scroll-locking.
- **Optimized Performance**: Zero bloat, native lazy loading, async decoding, and CDN preconnects.

## 🚀 Pages Included

- `index.html` — Homepage featuring hero section, bento showcase, flagship drops, and customer reviews.
- `shop.html` — Catalog with category filters and live search.
- `product.html` — Single product page with image gallery and size selector.
- `cart.html` — Shopping bag page with order overview.
- `checkout.html` — Two-step checkout with contact, shipping, and COD payment options.
- `about.html` — Brand heritage and engineering story.
- `contact.html` — Customer support channels and direct WhatsApp link.
- `privacy.html` — Privacy policy.
- `terms.html` — Terms of service.

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**: Framework-free, lightweight, and ultra-fast.
- **Modern CSS3**: CSS Grid, Flexbox, CSS Variables, and custom backdrop filters.
- **Font Awesome 6**: Vector icons via CDN.
- **Lenis**: Smooth scrolling engine.
